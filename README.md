# AttendX-Test-Scripts

## Project Description
This repository contains sample test scripts for the AttendX
student attendance application.

## Files
- login_test.py: Tests valid and invalid login credentials.
- attendance_test.py: Tests attendance marking and input validation.

## Technologies
- Python
- Git
- GitHub

## Purpose
To maintain test scripts, track modifications, and collaborate
using version control.
